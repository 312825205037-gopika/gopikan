# Student Performance Analysis

## Project Title

**Student Performance Analysis System Using Java and HTML**

## Project Description

Student Performance Analysis is a web-based mini project developed using Java, HTML, CSS, Java Servlet, and Apache Tomcat.

The system accepts student information, subject marks, and attendance percentage. It automatically analyzes the student's academic performance.

## Technologies Used

* Java
* HTML5
* CSS3
* Java Servlet
* Apache Tomcat
* Eclipse IDE
* GitHub

## Features

* Student information entry
* Subject marks entry
* Total marks calculation
* Percentage calculation
* Grade calculation
* Pass/Fail calculation
* Highest subject identification
* Attendance analysis
* Overall performance analysis
* Responsive web interface

## Subjects

The system analyzes five subjects:

1. English
2. Mathematics
3. Science
4. Computer Science
5. Social Science

## Grading System

| Percentage | Grade | Performance       |

## Installation

### Step 1

Install Java JDK.

Check Java:

```bash
java -version
```

### Step 2

Install Apache Tomcat 10 or later.

### Step 3

Install Eclipse IDE for Enterprise Java and Web Developers.

### Step 4

Create a Dynamic Web Project named:

```text
StudentPerformanceAnalysis
```

### Step 5

Copy the Java Servlet into the Java source folder.

### Step 6

Copy `index.html` and `style.css` into the web folder.

### Step 7

Configure Apache Tomcat.

### Step 8

Run the project using:

```text
Run As → Run on Server
```
